### 🛠️ Diverterapia — SaaS de Gestão + Site Institucional
> Um sistema de gestão interna (SaaS) para centralizar agenda, presença, faltas e relatórios de uma clínica multidisciplinar pediátrica, além do site institucional da clínica para atendimento aos pais.

[![Código Fonte](https://img.shields.io/badge/GitHub-Em_Desenvolvimento-black?style=flat&logo=github)](link-do-repo) 

- **Fase Atual:** Estruturando o site institucional (seções da home, identidade visual) e planejando a arquitetura de dados do SaaS.
- Automação de confirmação de falta via WhatsApp integrada ao fluxo de agendamento.
- App instalável como PWA, com acesso via celular ou desktop, sem loja de aplicativos.
- Sendo construído com **React** · **Supabase** · **Vercel** · **Z-API**
